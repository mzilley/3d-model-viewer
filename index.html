3d-model-viewer

Add one script, then put a div where the model should appear. Visitors drag to rotate and scroll or pinch to zoom.

<script src="3d-model-viewer.js" defer></script>

<div data-glb="models/example.glb" data-alt="Describe the model" style="height:420px"></div>

To run this page, put a .glb file at models/example.glb. Model files are not included in this repo.

1. Inline on the page

2. Inside a pop-up

The div sits in a pop-up that's hidden when the page loads, the same way Elementor pop-ups work. The model only downloads when the pop-up opens.

Built on Google's model-viewer. Source on GitHub.
